# Shebash Fashion Design — Platform

Full-stack web platform for Shebash Fashion Design, Bida, Niger State, Nigeria.

## Services Covered
- Bespoke sewing & custom tailoring
- Ready-to-wear clothing sales
- Cloth stoning & beadwork embellishment
- Tailoring materials retail & wholesale
- Global brand awareness (lookbook/portfolio)

## Tech Stack
- **Frontend:** Next.js (React) — hosted on Vercel
- **Backend:** Django + Django REST Framework — hosted on Render
- **Database:** PostgreSQL via Supabase
- **Payments:** Paystack
- **Notifications:** Termii (WhatsApp/SMS)
